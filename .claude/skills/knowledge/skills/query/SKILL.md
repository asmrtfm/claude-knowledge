## Query Mode

Surface knowledge relevant to a search query or set of files.

1. If the query looks like file paths: grep `INDEX.md` for those paths, read matched entries.
2. If the query is a topic: grep entry filenames and `INDEX.md` for keywords, read matched entries.
3. Present matched knowledge concisely. Do not dump entire entries — summarize what's relevant to the query.
